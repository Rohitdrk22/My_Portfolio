🖼️ Featured Project
Modern Developer Portfolio Website

A fully responsive and interactive portfolio website built with React, TailwindCSS, and Vite. Designed to help developers showcase their skills, projects, and professional experience with modern UI/UX principles, smooth animations, and dark mode support.

✨ Key Highlights
Responsive design for desktop, tablet, and mobile devices
Dark & Light mode with persistent theme settings
Interactive project showcase with live demo and GitHub links
Animated hero section and smooth scroll effects
Skills section with categorized technologies
Contact form with social media integration
Fast performance powered by Vite
Clean and scalable component architecture
🛠️ Technologies Used
React
TailwindCSS
Vite
Lucide Icons
Radix UI
JavaScript / TypeScript
🚀 Project Goals

The goal of this project was to create a professional personal portfolio that demonstrates frontend development skills while maintaining excellent performance, accessibility, and user experience.
